# AI 安全个人科研工作区

本系统用于执行一个持续 12 个有效研究周的本科生科研计划，主线是“AI 赋能漏洞检测与代码安全”。

## 两个目录的职责

- 主工程中心：`D:\Users\LENOVO\Desktop\科研`
  - 保存科研画像、路线、日报、周报、论文笔记、idea 和 Codex 导师反馈。
- 正式实验工作区：`D:\Users\LENOVO\Desktop\research`
  - 保存代码、虚拟环境、数据集、notebook、checkpoint 和正式实验结果。

不要把大型数据、模型权重或虚拟环境复制到主工程中心。日报和周报通过文件路径、实验编号或 Git 提交号引用正式实验工作区中的证据。

## 提交机制

- 正式汇报从 2026-08-16 开始。
- 没有固定提交时间，也不要求每天都提交。
- 每完成一次有效学习、论文阅读、环境配置或实验后，可随时向 Codex 提交日报。
- 周报推荐每 7 天左右提交一次，但由你自主决定具体日期和时间。
- 收到报告后，Codex 当次完成评价、追问、文件更新和下一任务安排。

## 模板与归档路径

- 日报模板：`D:\Users\LENOVO\Desktop\科研\template\日报模板.md`
- 周报模板：`D:\Users\LENOVO\Desktop\科研\template\周报模板.md`
- 日报归档：`D:\Users\LENOVO\Desktop\科研\research\daily\YYYY-MM-DD.md`
- 周报归档：`D:\Users\LENOVO\Desktop\科研\research\weekly\YYYY-Www.md`

使用规则：

1. 复制对应模板，不直接修改模板原件。
2. 将文件重命名为实际日期或 ISO 周编号。
3. 不适用或当天没有开展的部分填写“无”。
4. 把报告内容发给 Codex，或明确告知已保存的报告路径。
5. Codex 会在报告底部填写导师反馈，并同步路线、idea 和变更日志。
